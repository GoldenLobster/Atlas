# Atlas 

A cross-platform file manager written entirely in Java.

Inspired by KDE Dolphin, Atlas aims to provide a consistent, feature-rich file management experience across Windows, Linux, and macOS.

## Goals

- Cross-platform compatibility

- Clean and intuitive interface

- Efficient file management

- Extensible architecture

## Technologies

- Java

- Flatlaf(soon)

## Project Status

Very early development. I just started the project, it is in its very early stages.
